## 🎯 Как играть
**Онлайн:** https://tankario.onrender.com/
**Локально:**
```bash
# Клонируй репозиторий
git clone https://github.com/Daniil2013-RGB/Tankario.git
cd Tankario
# Установи зависимости
npm install
# Запусти
npm start
Открой http://localhost:3000
---
🎮 Управление
Клавиша	Действие
WASD / ЦФЫВ	Движение
ЛКМ / Пробел	Стрельба
U	Улучшения

## ⚙️ Возможности
- **VS BOTS** — одиночная игра с AI
- **Мультиплеер** — создай комнату и играй с друзьями
- **4 режима сложности** — Easy, Medium, Hard, Hardcore
- **Система улучшений** — Speed, Armor, Damage
- **Валюта Agarki** — зарабатывай за убийства
- **Выбор танков** — Basic, Speed, Heavy, Code
