
## Concept & Vision

Минималистичный онлайн танковый агарио с ASCII-эстетикой. Вид сверху в 3D на Three.js, но UI и визуальные элементы стилизованы под командную строку — рамки из символов `┌─┐│└─┘`, юникод-танки (▲▼●), терминальные шрифты. Ощущение: будто играешь в танчики через SSH в 2077 году.

## Design Language

### Aesthetic Direction
Ретро-терминал встречает киберпанк. Тёмный фон с неоновыми акцентами, но всё обрамлено ASCII-символами. Меню как диалоговые окна терминала. Игроки видят танки в стиле ASCII-арта.

### Color Palette
- **Background**: `#0a0a0f` (глубокий космический чёрный)
- **Primary text**: `#00ff88` (матричный зелёный)
- **Secondary text**: `#888899` (приглушённый серо-синий)
- **Accent 1**: `#ff6b35` (неоновый оранжевый для врагов/угроз)
- **Accent 2**: `#00d4ff` (кибер-голубой для игрока)
- **Accent 3**: `#ffdd00` (жёлтый для снарядов/улучшений)
- **Grid lines**: `#1a1a2e` (тёмно-фиолетовый)

### Typography
- **Primary**: `'Fira Code', 'Consolas', monospace` — для всего UI
- **Sizes**: 14px base, 12px hints, 18px headings

### Spatial System
- Все элементы обрамлены ASCII-рамками
- Padding кратен 8px
- Консистентные отступы: 16px между блоками

### Motion Philosophy
- Минимальные анимации — только функциональные
- "Печатающийся" текст для важных сообщений
- Плавное следование камеры (lerp 0.08)

### Visual Assets
- Танки: ASCII/Unicode представление или стилизованные low-poly с неоновым свечением
- Еда: мерцающие блоки/кубы
- Снаряды: яркие линии или круги
- Рамки: `┌─┐│└─┘╔═╗║╚═╝`

## Layout & Structure

### Screens

1. **Terminal Menu** — стартовый экран в стиле терминала
   - ASCII-art логотип
   - Ввод ника в стиле `$ login: `
   - Команды: `CREATE GAME`, `JOIN [CODE]`
   - Список подсказок управления внизу

2. **Lobby** — комната ожидания
   - ASCII-рамка с кодом комнаты
   - Список игроков с индикаторами статуса
   - Preview танка (вращающийся 3D или ASCII-art)
   - Команды: `READY`, `LEAVE`

3. **Game** — игровой экран
   - Canvas на весь экран
   - HUD в углах (ASCII-рамки):
     - Верх-лево: HP, очки, уровень
     - Верх-право: лидерборд
     - Низ-лево: выбранное оружие/урон
     - Низ-право: подсказки управления
   - Панель улучшений (появляется по команде)

4. **Death/Respawn** — overlay в терминальном стиле
   - `> PLAYER [name] DESTROYED`
   - Обратный отсчёт респавна

## Features & Interactions

### Core Gameplay
- Движение: WASD (и русская раскладка)
- Стрельба: клик/пробел
- Улучшения: U → панель выбора
- Сбор еды для очков и опыта
- Убийство врагов даёт бонусы

### Room System (Firebase)
- Создание комнаты → получение 4-символьного кода
- Присоединение по коду
- Готовность игроков → автозапуск
- До 8 игроков в комнате

### Upgrade System
- **Speed** (🚀): увеличение скорости (5 уровней)
- **Armor** (🛡): HP и размер (5 уровней)
- **Damage** (⚔): урон снарядов (5 уровней)
- Очки улучшений даются за повышение уровня

### States
- `menu` → `lobby` → `playing` → (respawn) → `playing`
- Все переходы анимированы в терминальном стиле

## Component Inventory

### Terminal Input
- Monospace шрифт, зелёный текст на чёрном
- ASCII-рамка: `┌────────────────────┐`
- Состояния: default, focus (яркая рамка), error (красная рамка)

### Player List Item
- `▶ [nickname]` — default
- `✓ [nickname] READY` — готов
- `👑 [nickname]` — хост

### Health Bar
- ASCII progress: `████████░░ 80/100`
- Цвет меняется: зелёный > жёлтый > красный

### Leaderboard
```
╔══ TOP PLAYERS ══╗
║ 1. Player    125 ║
║ 2. Tank      098 ║
╚═════════════════╝
```

### Upgrade Button
```
┌──────────┐
│  SPEED   │
│   🚀     │
└──────────┘
```
- Hover: подсветка
- Disabled: серый, неактивный
- Active: яркая рамка

## Technical Approach

### Stack
- **Frontend**: HTML5 Canvas + Three.js (3D рендеринг)
- **Backend**: Firebase Realtime Database (мультиплеер)
- **Styling**: CSS с терминальной эстетикой

### Architecture

```
Client:
├── index.html          #SPA с экранами
├── main.js             #Game loop, rendering
├── style.css           #Terminal UI
└── firebase.js         #Firebase integration

Firebase Structure:
├── /rooms/{roomId}/
│   ├── hostId: string
│   ├── state: "waiting" | "playing"
│   └── players/{playerId}/
│       ├── nickname: string
│       ├── x, z, angle: number
│       ├── hp, maxHp: number
│       ├── score: number
│       ├── ready: boolean
│       └── upgrades: { speed, size, damage }
├── /game/{roomId}/
│   ├── food: { [id]: { x, z, value } }
│   └── bullets: { [id]: { x, z, vx, vz, ownerId } }
└── /meta/{roomId}/lastUpdate: timestamp
```

### Sync Strategy
1. Каждый клиент пишет своё состояние в Firebase
2. Слушает изменения других через `onValue`
3. 30 FPS tick для позиций
4. Balloon updates для оптимизации (batch changes)

### Deployment
- Firebase Hosting для клиента
- Firebase Realtime Database (free tier: 100 concurrent connections)
